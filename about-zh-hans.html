G25 GeoMap——免费的遗传距离地图

G25 GeoMap 是一款免费、无广告的网页工具，它根据你勾选的样本与内置数据集中其他所有样本之间的遗传距离为世界地图着色。距离是基于 25 个 Global25（G25）坐标计算的欧氏距离；其他每个样本按其到最近的已勾选样本的距离着色。

打开地图支持本站

你可以做什么

  • 在世界地图上浏览内置的 9,384 个 Global25（G25）样本数据集——包括现代和古代样本。无需上传任何内容。
  • 勾选整个国家或单个样本，观看地图颜色由近到远的变化。
  • 筛选现代和历史样本，并按来源前缀筛选；已勾选的样本始终可见。
  • 浏览最近或最远样本的排名列表。
  • 将当前视图保存为 PNG 图片（含图例和一个小水印），或将所有距离导出为 CSV 表格。
  • 可使用多种界面语言，并可选择深色或浅色主题。

使用方法

  1. 打开地图——数据集会自动加载。
  2. 在“样本”面板中勾选一个国家或单个样本，或直接点击地图上的点。
  3. 对照图例读取颜色；将鼠标悬停在某个点上查看其名称和距离；滚动缩放，拖动移动。
  4. 调整筛选、色阶和外观，然后保存 PNG 或 CSV。

首次访问时会打开一段简短的导览，之后可随时通过导览按钮重新打开。

数据

地图附带一个数据集，AllG25_final_prefixed_v7.txt：共 9,384 个样本，每个样本带有其 25 个 G25 坐标。样本会被放置在其名称末尾所写的纬度和经度上，例如 Iran_Tehran_Sample-01_35.71_51.41。名称中含有 Historical 的样本视为历史样本，名称的前缀则表明该样本来自哪个数据集合（moriopoulos_ 8,299、G25_ 1,085 样本）。

Global25（G25）坐标系统由 Davidski（Eurogenes）创建。G25 GeoMap 是一个独立的查看器：样本集的功劳属于收集并发布它们的人，本站与他们无隶属关系，也未获得他们的认可。

隐私

一切都通过 JavaScript 在你的浏览器中计算。页面从本站加载其数据集文件，不会向任何地方发送任何关于你的信息。没有账户，也没有广告或跟踪脚本。本站只会在你浏览器的本地存储中记住你的偏好（语言、主题、面板宽度，以及你是否看过导览或隐藏了吉祥物）。

可选的地图背景会从第三方图块服务器（Esri 或 OpenStreetMap）加载，它们可以看到你查看的地图区域和你的 IP 地址；默认的“无图块”背景不会加载任何内容。如果你点击可选的 WalletConnect 捐赠按钮，才会在那一刻从 jsDelivr CDN 加载钱包库并连接到 WalletConnect 网络。如果你打开反馈页面并点击显示评论框，评论框由 giscus（giscus.app）和 GitHub 提供，它们随后可以看到你的 IP 地址；在你点击之前不会从它们加载任何内容。

须知

本工具仅用于学习和满足好奇心。样本之间的距离是遗传相似性的统计摘要，不构成医疗、法律或祖源方面的建议。

可选的底图图块（OpenStreetMap 贡献者、Esri）只有在你选择后才会从其提供方加载。使用本站生成的地图和 PNG 图片带有一个含站点名称的小水印。

界面和这些页面提供多种语言版本。翻译在 AI 辅助下完成，可能存在错误——请在反馈页面报告。
