انتقادات و پیشنهادات

انتقاد، ایده، اشتباهی که دیدید یا قابلیتی که کم است — همه‌ی این‌ها ابزار را بهتر می‌کند. نظرتان را در پایین بنویسید. نظرها عمومی‌اند و برای نوشتن آن‌ها به یک حساب رایگان GitHub نیاز دارید.

یا در GitHub یک issue باز کنید

با کلیک روی دکمه، بخش نظرات از giscus.app (که روی GitHub Discussions کار می‌کند) بارگذاری می‌شود و آن‌ها آدرس IP شما را خواهند دید. پیش از کلیک چیزی بارگذاری نمی‌شود.

بخش نظرات در حال راه‌اندازی است. تا آماده شدن، لطفاً به‌جای آن از پیوند GitHub استفاده کنید.
