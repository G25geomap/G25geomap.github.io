G25 GeoMap – eine kostenlose Karte der genetischen Distanz

G25 GeoMap ist ein kostenloses, werbefreies Web-Tool, das eine Weltkarte nach der genetischen Distanz zwischen den von Ihnen angehakten Proben und jeder anderen Probe seines integrierten Datensatzes einfärbt. Die Distanzen sind euklidische Distanzen über die 25 Koordinaten von Global25 (G25); jede andere Probe wird nach ihrer Distanz zur nächsten angehakten Probe eingefärbt.

Karte öffnenDie Seite unterstützen

Was Sie tun können

  • Erkunden Sie einen integrierten Datensatz mit 9.384 Proben von Global25 (G25) – modern und antik – auf einer Weltkarte. Es muss nichts hochgeladen werden.
  • Haken Sie ein ganzes Land oder einzelne Proben an und sehen Sie zu, wie sich die Karte einfärbt: von nah bis fern.
  • Filtern Sie moderne und historische Proben sowie nach Quellpräfix; angehakte Proben bleiben immer sichtbar.
  • Durchsuchen Sie eine Rangliste der nächsten oder fernsten Proben.
  • Speichern Sie die aktuelle Ansicht als PNG-Bild (mit Legende und einem kleinen Wasserzeichen) oder exportieren Sie alle Distanzen als CSV-Tabelle.
  • Nutzen Sie die Oberfläche in mehreren Sprachen, im dunklen oder hellen Design.

So geht’s

  1. Öffnen Sie die Karte – der Datensatz wird automatisch geladen.
  2. Haken Sie im Bereich „Proben“ ein Land oder einzelne Proben an oder klicken Sie auf Punkte der Karte.
  3. Lesen Sie die Farben anhand der Legende ab; fahren Sie mit der Maus über einen Punkt, um Name und Distanz zu sehen; mit dem Scrollen zoomen Sie, durch Ziehen verschieben Sie die Karte.
  4. Passen Sie Filter, Farbskala und Darstellung an und speichern Sie dann ein PNG oder CSV.

Beim ersten Besuch öffnet sich ein kurzer geführter Rundgang, den Sie jederzeit über die Schaltfläche Rundgang erneut öffnen können.

Die Daten

Die Karte enthält einen Datensatz, AllG25_final_prefixed_v7.txt: 9.384 Proben, jede mit ihren 25 G25-Koordinaten. Eine Probe wird bei dem Breiten- und Längengrad platziert, der am Ende ihres Namens steht, zum Beispiel Iran_Tehran_Sample-01_35.71_51.41. Namen, die Historical enthalten, gelten als historische Proben, und das Präfix eines Namens zeigt, aus welcher Sammlung die Probe stammt (moriopoulos_ 8.299, G25_ 1.085 Proben).

Das Koordinatensystem Global25 (G25) wurde von Davidski (Eurogenes) entwickelt. G25 GeoMap ist ein unabhängiger Viewer: Die Anerkennung für die Probensätze gebührt den Menschen, die sie gesammelt und veröffentlicht haben; die Seite ist weder mit ihnen verbunden noch von ihnen unterstützt.

Datenschutz

Alles wird in Ihrem Browser mit JavaScript berechnet. Die Seite lädt ihre Datensatzdatei von derselben Seite und sendet nichts über Sie irgendwohin. Es gibt kein Konto, keine Werbung und keine Tracking-Skripte. Die Seite merkt sich nur Ihre Einstellungen (Sprache, Design, Breite der Seitenleiste, ob Sie den Rundgang gesehen oder das Maskottchen ausgeblendet haben) im lokalen Speicher Ihres Browsers.

Optionale Kartenhintergründe werden von Kachelservern Dritter (Esri oder OpenStreetMap) geladen, die den angezeigten Kartenausschnitt und Ihre IP-Adresse sehen können; der Standardhintergrund „Keine Kacheln“ lädt nichts. Wenn Sie auf die optionale WalletConnect-Spendenschaltfläche klicken, wird eine Wallet-Bibliothek vom jsDelivr-CDN geladen und verbindet sich nur in diesem Moment mit dem WalletConnect-Netzwerk. Wenn Sie die Feedback-Seite öffnen und klicken, um das Kommentarfeld anzuzeigen, wird es von giscus (giscus.app) und GitHub bereitgestellt, die dann Ihre IP-Adresse sehen können; vor dem Klick wird nichts von ihnen geladen.

Die Seite unterstützen

G25 GeoMap ist kostenlos. Wenn es Ihnen geholfen hat und Sie Danke sagen möchten, können Sie eine kleine Krypto-Spende senden – sie ist völlig freiwillig. Öffnen Sie Ihre Wallet mit einem Klick oder kopieren Sie eine Adresse (zuerst USDT auf TRON, dann USDT und USDC in anderen Netzwerken, TRX, ETH, BNB, BTC, TON, SOL). Jeder Betrag wird geschätzt.

Feedback & Vorschläge

Einen Fehler gefunden oder Kritik bzw. einen Vorschlag? Hinterlassen Sie einen Kommentar auf der Feedback-Seite. Kommentare sind öffentlich und nutzen Ihr kostenloses GitHub-Konto; Sie können auch direkt auf GitHub ein Issue eröffnen.

Gut zu wissen

Dieses Tool dient der Bildung und der Neugier. Distanzen zwischen Proben sind eine statistische Zusammenfassung genetischer Ähnlichkeit und stellen keine medizinische, rechtliche oder Herkunftsberatung dar.

Optionale Basiskarten-Kacheln (OpenStreetMap-Mitwirkende, Esri) werden nur von ihren Anbietern geladen, wenn Sie sie auswählen. Mit dieser Seite erstellte Karten und PNG-Bilder tragen ein kleines Wasserzeichen mit dem Namen der Seite.

Die Oberfläche und diese Seiten sind in mehreren Sprachen verfügbar. Die Übersetzungen wurden mit KI-Unterstützung erstellt und können Fehler enthalten – bitte melden Sie diese auf der Feedback-Seite.
